# Authority map — who may do what, and where to stop

Classes (see `charters/authority.md`): `owner-only`, `company-alternate`, `attorney-alive`,
`executor-after-death`, `provider-decides`, `professional-step`.

| Capability | Who may act | Instrument / evidence | Confirmed with provider (date) | Stop point |
|---|---|---|---|---|
| Renew or transfer the domain | | | `unknown` | registrar support route |
| Access hosting / deploy | | | `unknown` | provider support |
| Change payment account | | | `unknown` | bank + provider |
| Bank mandate | | | `unknown` | **bank step — professional** |
| Cancel a subscription | | | `unknown` | provider |
| Close or transfer the company | | | `unknown` | **solicitor / Companies House** |

## Jurisdiction notes

- England & Wales: LPA (property & financial affairs) while alive; executor/probate after death.
- Scotland: Continuing/Welfare PoA while alive; **confirmation** after death.

Nothing in this table is legal advice. Where the answer is `unknown`, the procedure says who to ask.
