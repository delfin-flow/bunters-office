# How to write this document (rules, applied)

The reader is tired, unfamiliar with the business, and possibly grieving. Short, plain, checkable — and
never a chat.

## The shape

1. **What this is** — two sentences, no adjectives.
2. **First safe actions** — numbered, imperative, one action each.
3. **The steps** — the order things actually break in, with what you should see after each one.
4. **Stop points** — where a professional must act.
5. **What is not covered** — dated list of what nobody has verified.
6. **Checklists** — tickable, for the first day and the first week.

## The rules

- **One idea per sentence.** If a sentence has two "and"s, split it.
- **Imperative for actions** ("Open the registrar's support page"), declarative for facts ("The domain is
  held by the company").
- **Every action ends in an observable result** — or says that nothing will change.
- **Every claim carries a date** and, where it matters, its source. A claim without a date is written as
  `unknown`, not as fact.
- **Do not upgrade uncertainty.** "Should be", "usually", "normally" are not evidence. Say what was checked,
  when, and what was not.
- **No adjectives you cannot check.** Robust, seamless, comprehensive, easy: delete them, or replace with the
  fact that justified them.
- **Define a term the first time** ("a registrar — the company that holds the domain name"), then use it
  consistently. One name per thing, everywhere, including in the tables.
- **Numbers, dates and names exactly as recorded** — no rounding, no "around", no reformatting that changes
  meaning.
- **Say who acts**: "you" means the reader, always. Never "one", never "we" unless it means the business.
- **Structure before wording.** If the order is wrong, rewriting sentences is a waste of everyone's time.
- **Length follows consequence**, not completeness. Under ten pages; a document nobody finishes is a
  document nobody follows.

## What the writer must never do

- Invent a fact, a source, a price, a date or a provider process.
- Resolve a legal or financial question by writing around it. Name the professional.
- Reduce a risk to a reassuring sentence. A known gap, written plainly, is worth more than a smooth page.
- Copy someone's private notes into a public place — including into an issue about this document.
