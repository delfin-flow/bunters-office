# 01 — v0.1.0: the scaffold, the tools, the environment (S1, S2, S10)

**Delivered**
- The record's shape as templates (profile, accounts/assets CSV, dependency map, authority map, procedure,
  drill log) and eleven charters stating what each part must be.
- Deterministic tools: `install.sh`, `doctor.sh`, `status.sh`, `package-export.sh`, `bundle-verify.sh`,
  `uninstall.sh` — offline, no model, no network.
- The environment recorded once at installation (`store/environment.md`) instead of guessed per session.

**Decisions & deviations**
- The workspace is detected by the presence of `store/`, not a marker file: a tracked marker made the tree
  dirty after installation, which would have blocked updates forever.
- Vendored skill/agent conventions were not copied in; the contracts are this project's own words.

**Known issues**
- The macOS and Windows (Git Bash) branches of `doctor.sh` are written but unprobed.
- No automated test for the tools; each was verified by hand in a clean directory.

**Hand-off to next story**
Read `charters/first-run.md` before touching collection; the tools assume `store/` exists and already say so.
