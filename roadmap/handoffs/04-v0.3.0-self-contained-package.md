# 04 — v0.3.0: the package works on its own (S18)

**Delivered**
- `package-skills/`: `guide-handover`, `produce-document`, `write-plainly` — the only skills a bundle carries.
- `package-export.sh` ships those, `document/TEMPLATE.md` and the package's own `README.md`; maintenance
  tooling stays in the workspace.
- The document's writing rules travel **inside** the bundle as text, not as a reference.

**Decisions & deviations**
- The private editorial workspace was consulted for the writing rules, which were then **re-expressed in this
  repository's own words** — private guideline content must not be copied into a public repository. The
  registry, registers and severity model stay private; the rules that matter to a reader are embedded (D17).
- A bundle deliberately contains no scripts: a document produced from it years later looks like one produced
  today, and cannot fail because a script rotted.

**Known issues**
- Nobody has yet produced a document from a bundle in the real world (S5).

**Hand-off to next story**
If a bundle ever needs a fourth skill, ask whether it is *using* the package or *maintaining* it. Maintenance
stays in the workspace.
