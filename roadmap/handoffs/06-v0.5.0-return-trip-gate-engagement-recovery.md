# 06 — v0.5.0: the return trip, the rotation gate, engagement and recovery (S21–S26)

**Delivered**
- **Two-way transfer** — `scripts/bundle-import.sh` + `skills/import-bundle`: a bundle restores into a fresh
  `store/` (checksums verified, refusal to overwrite, reconstructed `settings.yaml`, `import:` commit); CI
  proves the round-trip.
- **Rotation gate** — `package-export.sh` writes `rotation.overdue`/`rotation.exposed` into the manifest;
  `bundle-verify.sh` fails while either is non-zero; `WORKSPACE.md` non-negotiable #9 + `charters/secrets.md`
  state the gate and its single escape (a logged refusal with a new `next_due`); CI plants an overdue row and
  asserts refusal.
- **Engagement contract** — `charters/engagement.md` (the escalation ladder), `store/gaps.md`, `store/coverage.md`,
  counted by `status.sh`.
- **Recovery flow (P5)** — `skills/recover` + a generated `recovery/restore-order.md` + a drill task for the
  return trip.
- **Feature-request route** — `.github/ISSUE_TEMPLATE/feature.yml` + `charters/feedback.md` traceability.
- **Infrastructure protection** — `templates/procedures/domain-lockdown.md`, `email-master-key.md`,
  `backup-3-2-1.md`.

**Decisions & deviations**
- D19–D23 record the reasoning (two-way transfer, rotation as a gate not an automation, the engaged employee,
  recovery as a flow, requests sharing the issue channel).
- Origin single-sourcing was implemented as a **CI consistency check + site link + version reconcile** rather
  than a new `ORIGIN.yml` that nothing would read — the defect (drift, missing maker link) is fixed without an
  unread artifact.

**Known issues**
- The rotation gate counts overdue by `next_due` (or `last_rotated`+`policy_months`); a manually-edited
  register can still smuggle a bad date past it — the gate is discipline, not cryptography.
- `bundle-import.sh` does not restore the rotation register, environment probe, adaptations, footprint or
  package remote (by design, D19) — an import is a hypothesis until re-verified.

**Hand-off to next story**
S5 (a real drill and a real alternate) now has two extra tasks to prove: domain lockdown and the
bundle-import return trip. S4 (authority gate) and S6 (reminders without a daemon) remain the closest
unproven rungs.
