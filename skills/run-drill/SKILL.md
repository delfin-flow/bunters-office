# Run a drill

1. Confirm the preconditions: a chain that is verified, procedures that exist, and an alternate who is not
   the owner. If not, say what is missing and propose the next freshness session instead.
2. Export a fresh bundle (`skill: export-bundle`). The alternate uses **the bundle**, not the machine.
3. Set the rules out loud (`charters/drill.md`): owner silent unless something is about to be destructive;
   safe tasks only — locate, read, verify; never move money, delete, cancel or change ownership.
4. Give one task at a time from the mandatory set (registrar ownership, the transfer/renewal support route
   and its evidence, the code repository, the last backup and its date, the payment route and its stop
   point). Time each one.
5. **Record the failures, not the successes**: every moment the owner had to supply something not written
   down is a defect. Write `store/drill/YYYY-MM-DD-<alternate>.md`, correct the record, commit the package.
6. Re-export the bundle so its `evidence/drill/` carries the proof, and say plainly what a reader can now
   rely on — and what they still cannot.
